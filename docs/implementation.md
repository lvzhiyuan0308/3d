# 实现与来源

## V1 薄片的来源

V1 中 `layered.py` 曾额外构造 `Hair front lock` 片状网格，并把后发做成约 3 mm（人体尺度）的壳层。这不是阶段 3 的 SMPL-X 法线位移结果。

V2 删除前侧薄片，后发为闭合、带端盖的体积，内壁埋入头部与上背；头皮帽加厚后与头部交叠。GLB 保留分层编辑，打印版才实体化融合。

头部前后表面的网格密度极不均衡：使用后侧顶点的低分位数仍可能选中密集面部点，把头发推到脸前。修正使用后表面包络，并在专项验证中检查发块内壁相对人体背面的偏移。

## 贴图

1. 由部件生成顶点/面标签，源像素采用保守的颜色和区域规则。
2. 可靠源像素腐蚀 2 px。每个三角形测试三个顶点、三个边中点与重心的标签和深度，容差为人体尺度 8 mm。
3. 白色衣物、蓝裙各自生成已清理的源图；未观测区域用同类补色，不退回遮挡它的原始像素。这样同时保护三角形内部和来源相机选择。
4. 手臂袖子使用不透明图案；身体使用同一条低对比度肤色渐变；头发使用程序颜色。

规则标签不是真实语义真值。筛选报告中的“类别一致”仅指这些标签，不能解释为分割精度或照片还原精度。

## 脸部

V1 只把参考图关键点变形到原照片，忽略实际模型五官的位置。V2 使用 SMPL-X 静态 51 点与照片 MediaPipe 关键点对应，辅以轮廓控制；单张照片投影到模型面部，边缘按有效投影支持区域羽化。包含眼球、下颌区域的权重分组。

这里只改变外观纹理，没有执行 MICA/DECA/FLAME 身份几何重建。原照片参与了贴图，不是 holdout，不能据此报告身份准确率或独立 LPIPS 得分。

## 仍有样例相关假设

颜色规则、衣物几何、身高先验和打印高度是本次样例的工程假设；裁切/脸部 ROI 可配置，但换人或换服装后仍需重新检查规则与几何。打印版固定 200 mm。

本项目参考用户提供的共享方案中共享体型、多视图拟合、SMPL-X+D、UV 投影与打印处理等概念。未成功取得该共享页面的阶段脚本包，当前代码为本地独立实现，不能视作对其原始脚本的完整复现。
